# Contributing to RadioThermal_Soldering_OSHW #
These are the general guidelines for contributing to the RadioThermal_Soldering_OSHW project.

## AI Contributions

Content generated by any LLM (also known as AI) may not be contributed in issues or PRs to this project including schematics, PCB layouts, code, comments, descriptions, and documentation.

## PCB designs

There is a general expectation that all PCB design changes have been tested and confirmed working before contribution. If submitting a PCB design change, please provide proof that the board is operating as expected.
